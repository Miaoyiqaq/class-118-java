## 用户介绍
"我"(opencode用户)是一个计算机专业的大二学生.我目前掌握了 java 语法 和 java 数据结构相关知识,接下来准备学习HTTP相关内容

## 项目介绍
该项目是一个学习类项目,通过 java 原生的 TCP socket 创建一个简单的 HTTP 服务器程序.通过这个程序来加深我对HTTP协议的理解

## 项目要求
1. 通过TCP socket 绑定9090端口
2. 通过多线程方式处理多个TCP连接(每个TCP连接分配一个线程),通过线程池来组织多个线程
3. 定义好类,描述一个 HTTP 请求和 HTTP 响应的具体结构
4. 只需要支持HTTP/1.1协议即可,其它版本无需考虑
5. 只处理 GET 和 POST请求
6. 请创建好一个父类,来完成 HTTP 请求/响应 解析构造操作,我可以写一个新的子类,在子类中完成对请求的具体处理逻辑
